# cash-bite 개선 작업 계획 (피드백 기반)

> 실제 코드 감사에 근거한 계획. 작성 시점 기준 **복리·배당포트폴리오·물타기는 비활성** —
> 해당 화면의 용어/로딩 보강은 재활성 시점으로 후순위. 활성 화면(홈·뉴스·거장·거시·환율바)에 집중.

## 0. 피드백 ↔ 실제 코드 대조

| 피드백 | 실제 코드 상태 | 판정 |
|---|---|---|
| 거시 차트 "빈 흰 박스" | 스켈레톤은 있으나 저품질(내부 구조 없는 pulsing 박스)→ 빈 박스로 읽힘 + 레이아웃 시프트 | 부분 사실 |
| 빈/로딩/에러 전반 | NewsPage만 고품질. 환율바/지수=스켈레톤 無·무음 실패, 홈 다이제스트=스피너만·에러 無, Guru=구조만 | 사실 |
| 명언 도트 비직관 | 50개, "다음"(랜덤) + 클릭 불가 장식 도트 + "23/50". 이전 버튼·라벨 없음 | 사실 |
| 뉴스 "전부 4분 전/NAVER" | 시각은 실제·정상(Naver pubDate). 군집=최신순 특성 + 언론사명 미캡처로 전부 "naver" | 재해석 |
| 13F/DRIP 툴팁 필요 | 툴팁 프리미티브 0개. 활성 미설명 용어: 13F·Put/Call·YoY/MoM·DRIP | 사실 |
| 홈 정체성 없이 뉴스부터 | 히어로 없음. home.heroTitle/Subtitle/CTA i18n 키 정의됐으나 미사용(고아) | 사실 |
| 포인트 컬러 | 액센트=흑백 모노. 개미 포인트 컬러 없음 | 사실 |

## WS-1 · 로딩/빈/에러 상태 일원화 (완성도) — 우선 高
- 1-0 (S): 공용 `<Skeleton>`(shimmer)·`<EmptyState>`·`<ErrorRetry>` 프리미티브 신설
- 1-1 (M): MacroPage 스켈레톤 고도화(내부 라인/차트 자리) + 마운트 즉시 로딩 + 레이아웃 시프트 제거
- 1-2 (S): ExchangeRateBar 지수 로딩 스켈레톤 + 실패 시 재시도/표시
- 1-3 (S): MarketNewsPreview 2섹션 스켈레톤 + 에러 재시도
- 1-4 (S, opt): GuruPage LoadingSkeleton 내부 라인/shimmer
- 수용기준: skeleton→content 레이아웃 시프트 0, 에러 시 재시도 노출

## WS-2 · 초보자 용어 안내 (UX) — 우선 高
- 2-0 (M): `<InfoHint>` 프리미티브(hover+tap, a11y) + i18n `glossary` 블록(ko/en/ja)
- 2-1 (S): 활성 표면 배선 — 13F(GuruPage·GuruSummary·홈 tip3), Put/Call(HoldingsTable), YoY/MoM(MacroPage), DRIP(홈 tip1)
- 수용기준: 활성 화면 핵심 용어에 호버/탭 설명(ko/en/ja)

## WS-3 · 아이덴티티/브랜딩 (첫인상) — 우선 中上
- 3-1 (S, quick win): 홈 최상단 히어로 — 고아 키 활용 + "거장의 포트폴리오로 시작하는 개미의 투자 공부" 슬로건 + CTA. 섹션 순서 정체성 먼저로 재배치
- 3-2 (S): 개미 포인트 컬러 토큰(--cb-point) 추가 + 로고/히어로/CTA 적용(green/red 유지)
- 3-3 (S): QuoteOfDay 이전/다음 화살표+라벨, 도트 클릭화 또는 제거
- 수용기준: 홈 첫 화면에서 사이트 정체성 즉시 전달

## WS-4 · 뉴스 신뢰도(시각·출처) — 우선 中
- 4-1 (S): 절대 발행시각 병기(날짜+HH:MM)
- 4-2 (M): 백엔드 Naver 클라이언트에서 실제 언론사명/도메인 캡처(originallink) → publisher 채움
- 4-3 (S): backendNewsClient.normalize 의 Date.now() 폴백 제거(파싱 실패 시 "—")
- 수용기준: 실제 시각·실제 출처로 분산돼 "실시간감" 회복

## WS-5 · 데이터 기반 페르소나 분석 (신규/R&D) — 우선 低(별도 스파이크)
- 제약: 개인 데이터원 약함(배당 포트폴리오 비활성)
- 5-1 (spike): 데이터원·산출물 정의(거장 선호/성향 퀴즈 → 투자 성향 카드 + 거장 추천)
- 5-2 (L): 구현
- 수용기준: 별도 합의 후 착수

## 로드맵
- Phase 1 (quick wins): 3-1 히어로 · 4-1 절대시각 · 4-3 폴백 하드닝 · 1-2 환율바 스켈레톤
- Phase 2 (foundation+배선): 1-0 → 1-1·1-3·1-4 · 2-0 → 2-1
- Phase 3 (마감): 3-2 포인트 컬러 · 3-3 QuoteOfDay · 4-2 출처 캡처(백엔드)
- Phase 4 (별도): WS-5 페르소나 스파이크
